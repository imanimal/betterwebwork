WeBWorK, cleaned up

BetterWebWork is a free browser extension that redraws your WeBWorK homework so it's easier to read and work through. When an answer gets marked wrong, it tells you if WeBWorK read what you typed differently from what you meant.

    Your sets, in plain words

    The set page shows what you've finished and what's still half done, and the due date reads like "Thu 11:59 PM, in 4 days" instead of a timestamp. If you refresh halfway through a problem, what you'd typed is still in the blanks. On your last attempt, Submit asks you to press it a second time before it counts.

    Install it

    It's free and there's no account. The extension doesn't send anything anywhere, and your answers reach WeBWorK exactly as they would without it. Once it's installed, open a WeBWorK problem and it's already on.

    The store listings are in review. Until they're up, you can load it from the source.

    Firefox You're using this

    Add to Firefox

    Firefox 128 or newer.

    1. Download the code from GitHub and unzip it.
    2. Open about:debugging#/runtime/this-firefox.
    3. Click Load Temporary Add-on and pick manifest.json. It stays until Firefox restarts.

    Chrome and Edge You're using this

    Add to Chrome

    Chrome 111 or newer. Edge installs it from the same page.

    1. Download the code from GitHub and unzip it.
    2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
    3. Click Load unpacked and pick the folder.

    It runs on any WeBWorK site with /webwork2/ in the address. If a page looks off, you can turn it off for that site from the toolbar and tell me on GitHub.
